# Proposed First Issues

## 1. Establish untouched upstream baseline

Build and launch the pinned upstream commit without project renaming or feature changes. Record environment, commands, warnings, failures, and test evidence.

## 2. Validate dedicated-server compatibility

Test registry synchronization, creative inventory, eggs, hatching, taming, riding, saving, and reconnecting on a dedicated development server.

## 3. Map dragon extension seams

Document the responsibilities and coupling of `TameableDragon`, movement controllers, animator, model, renderer, breed registry, ability registry, eggs, camera controls, and mixins.

## 4. Prototype an independent placeholder species

Register one original placeholder species with a separate model and renderer while reusing only proven generic mechanics.

## 5. Decide foundation vs donor status

Based on the placeholder prototype, classify the upstream project as either the main foundation, a mechanics donor, or unsuitable.
